## Instructions

Your script will take an input path (in this case, "sample_XMLs") as input, where all the ECG XMLs live. I provided deidentified examples to work with. Your output path is designated as "sample_output". This script will loop through all XMLs in the folder, and output demographic information for each of the ECGs, and also conver the XML to a .hea/.dat file (facilitating downstream tasks such as conversion to .h5 and creation of ECG Photos.
